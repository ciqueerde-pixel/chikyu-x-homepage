# 株式会社CHIKYU X — Corporate Website

人の役に立つものを創造する。  
**NATURE × SPIRIT × TECHNOLOGY**

## 開発

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) で確認できます。

## ページ

- `/` — Home（MISSION / PROJECTS）
- `/company` — COMPANY
- `/contact` — CONTACT

## 技術

- Next.js (App Router)
- Tailwind CSS
- 日本語フォント: Zen Kaku Gothic New（HUMAN MADE社サイトと同系統）
